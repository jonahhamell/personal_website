Personal Website Version 2026_Summer, Created by Jonah Hamell in Summer 2026.

I wanted a way to easily show off projects that I have worked on to Employers, therefore, I thought that a website that talked a little bit about myself, that had a way to efficiently show off projects that I have worked on. 
  - Clicking on the project will tell you more about the project, the techniques that I learned while working on the project, and how    long it took for the project to be completed
  - If a project is currently being worked on, E.G. Authentica, then clicking on the project will show you current blueprints that I have for the project, as well as a project description.
